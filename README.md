# 🔐 Glassmorphism Login UI

### A modern, elegant Android login screen built with **Kotlin** & **Jetpack Compose**

[![Kotlin](https://img.shields.io/badge/Kotlin-100%25-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)](https://kotlinlang.org)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-UI-4285F4?style=for-the-badge&logo=jetpackcompose&logoColor=white)](https://developer.android.com/jetpack/compose)

**Glassmorphism Login UI** is a beautifully designed Android login screen implementing the popular **glassmorphism (frosted glass) design trend**, built entirely with **Kotlin** and **Jetpack Compose**. It's a great reference for developers learning modern Android UI design, Compose animations, and Material 3 styling.

## ✨ Features

- 🎨 **Glassmorphism (Frosted Glass) UI** — soft blur, transparency, and layered depth
- ⚡ **Built 100% with Jetpack Compose** — no XML layouts, fully declarative UI
- 🧩 **Reusable Composable components** for text fields, buttons, and cards
- 🌗 **Clean, modern design language** inspired by current UI/UX trends
- 📐 **Responsive layout** that adapts to different screen sizes
- 🛠️ **Beginner-friendly codebase** — great for learning Compose UI design patterns

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/zameeshajameel/Glassmorphism-Login-UI.git
   ```
2. **Open in Android Studio**
   - Launch Android Studio → `Open` → select the cloned project folder.
3. **Sync Gradle**
   - Let Android Studio download dependencies and sync the project automatically.
4. **Run the app**
   - Select an emulator or connected device, then click ▶️ **Run**.
